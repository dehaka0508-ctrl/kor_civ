# 지도자 대사 작성 기준

대사 원본은 엑셀에서 `tools/import_leader_lines.py`로 `korciv/data/leader_lines.json`에 옮긴다.

| 항목 | 기준 |
|---|---|
| 첫 조우 대사 | 지도자당 한 문장. 자기 이름은 직접 말하지 않고, 업적·일화·직위로 자기소개를 한다. |
| 우호 선언 대사 | 우호관계가 맺어질 때 하는 한 문장. 각 지도자의 일화나 성향을 우정의 표현으로 바꿔 쓴다. |
| 전쟁 발발 대사 | 전쟁이 시작될 때(선포하거나 선포받을 때) 하는 한 문장. 호전적인 지도자는 공세적으로, 평화 지향 지도자는 마지못해 맞서는 어조로 쓴다. |
| 플레이어 비난 대사 | 플레이어의 행동(국경 병력 배치, 요구, 동맹국 공격 등)을 비난할 때. 각 지도자가 중시하는 가치로 상대를 깎아내린다. |
| 동맹 체결 대사 | 우호 다음 단계인 동맹이 맺어질 때. 우호 선언보다 한 단계 깊은 결속을 표현한다. |
| 휴전 대사 | 강화(휴전)가 맺어질 때. 성향에 따라 안도, 마지못함, 다음을 기약하는 어조로 나눈다. |
| 멸망 대사 | 플레이어에게 마지막 영토를 잃을 때. 실제 유언·사세구가 알려진 인물은 그 말을 쓴다(수 양제, 당 태종의 회한, 도요토미 히데요시의 사세구, 이순신, 최영, 맥아더). |
| 승리 대사 | 플레이어를 멸망시켰을 때. 각자의 상징(활, 순수비, 성벽, 바다 등)으로 승리를 말한다. |
| 어조 | 호전성과 관계없이 첫 만남은 중립적인 인사, 우호 선언은 따뜻한 어조, 전쟁 발발은 성향에 따라 공세 또는 방어. 근현대 실존 인물은 승리·비난 대사도 절제된 표현을 쓴다. 고대~조선 인물은 고어체(~하오, ~노라), 근현대 인물은 현대 존댓말. |
| 외국 지도자 | 해당 국가 언어로 쓰고 괄호 안에 한국어 뜻을 붙인다. 중국 황제는 한문체(번체), 야율융서는 거란 문자가 온전히 해독되지 않아 요 조정이 함께 쓴 한문체, 마오쩌둥은 현대 중국어(간체), 쿠빌라이는 현대 몽골어 키릴 문자, 홍타이지는 만주어 로마자(묄렌도르프 표기), 일본 인물은 일본어, 스탈린은 러시아어, 맥아더는 영어. |
| 검수 권장 | 몽골어·만주어 문장은 원어 화자 또는 전공자 검수를 권장한다. 만주 문자 원문이 필요하면 로마자를 변환해 쓴다. |
