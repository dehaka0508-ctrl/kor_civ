# 특산물이 행복도에 주는 영향 (v1.45.0, 시뮬레이션 없이 공식·지도 데이터로)

## 1. 지금 크기
- 공급받는 특산물 1종마다 그 지역 행복도 턴당 +0.1, 한 지역 최대 5종.
- 행복도는 매 턴 (현재 + 입력) × 0.99 이므로 같은 입력이 계속되면 수렴값 = 입력 × 99.
  - 1종 = +9.9, 5종 = +49.5 (수렴값). 절반까지 69턴, 63%까지 100턴, 24턴 뒤 21%(+2.1), 48턴 뒤 38%(+3.8).
- 비교: 세율 1%p = 행복도 턴당 0.1 → **특산물 1종 공급 = 그 지역 세율 1%p 인하와 같다**(수렴값 ±9.9).
- 공급량: 426개 지역 중 166곳(39%)이 특산물 산지, 종류는 169종(거의 지역마다 1종). 특산물 시설 L단계 = 턴당 L개(최대 3).
  - N개 지역 나라는 산지 약 0.39N곳 → 3단계까지 지으면 턴당 약 1.17N개 → 지역마다 평균 1.2종 → 평균 행복도 수렴 +11.6.
  - 1단계뿐이면 평균 0.4종 → +3.9.
- 행복도가 쓰이는 곳: 산출(음수일 때만, −100에서 −30%, 제곱 곡선), 인구 성장(5 이상부터, 45에서 최대), 반란(−50 이하부터), 사기(평균 −10 이하부터 전투력 감소).
- 결론: 지금 특산물은 **'세율 1%p 남짓'의 느린 완충제**입니다. 반란 직전 지역을 살리기엔 느리고(수렴에 100턴 단위), 평시 세율을 1~2%p 더 올릴 여유를 주는 정도입니다.

특산물 효과를 올리면 이 격차가 더 벌어지고, 내리면 줄어듭니다. 특산물이 무역 상품이 된 v1.45.0부터는 산지가 많은 나라가 판매 수입까지 얻어 상향 시 이 편향이 더 커집니다.

## 3. 효과를 올리거나 내리면
| | 상향(예: 1종 +0.1 → +0.15) | 하향(예: +0.1 → +0.05) |
|---|---|---|
| 정복 | 유리: 점령지(저항·회복 뒤 낮은 행복도)와 전쟁 피로를 덮어 큰 나라가 덜 흔들린다. 거대국 독주(240턴 40% 이상 지도 차지 46%판)가 더 굳어질 위험 | 불리: 넓힐수록 반란·사기 부담이 커져 독주가 꺾인다 |
| 경제 | 유리: 세율을 더 올려도 버틴다(경제 방향은 이미 세율 +2%p). 인구 성장(행복도 5~45 구간)도 빨라져 GDP가 는다 | 불리 |
| 과학 | 소폭 유리(세율 여유만큼 착공 자금) | 소폭 불리 |
| 외교 | 유리: 특산물 거래가 잦아져 거래 우호도(+1×개수)가 쌓인다. 불행한 나라는 사야 하므로 산지가 많은 나라에 우호도가 몰린다 | 거래 동기가 줄어 우호도 경로 하나가 약해진다 |
| 시간 | 1위 굳히기 쪽에 유리(상향 시 정복과 같은 이유) | — |

지도자별:
- **상향 시 상대적으로 불리**:
  - 단군왕검 '홍익인간'(전 지역 턴당 +0.1 = 모든 지역에 특산물 1종 상시 공급): 남들이 따라잡아 상대 가치가 떨어진다.
  - 당 태종 '정관의 치'(세율 행복도 감소 −20%): 모두가 세율 여유를 얻어 우위가 희석된다. 너프 방향과 같다.
  - 세종대왕 '고기 없이는 못살아'(특산물 10개당 1개 감소): 특산물 값이 오른 만큼 손실도 커진다.
  - 홍경래 '민란의 불꽃'(점령지 행복도 +15): 점령지 행복도 문제를 모두가 특산물로 덮게 된다.
- **상향 시 상대적으로 유리**:
  - 야율융서 '전연의 맹약'(우호 선언마다 공물 특산물): 공물 1개의 가치가 오른다.
  - 박정희 '유신 체제'(15% 초과 세율 감소 ×1.5)·이승만 '3·15의 그늘'(평균 −30 이하 반란 ×2): 디버프 구간에서 벗어나기 쉬워진다.
  - 대조영 '유민 국가'(점령지 행복도 −10): 디버프가 가려진다.
  - 장보고: 동맹 없이 고립되는데, 특산물 거래 우호도(+1×개수)가 새 관계 경로가 된다.
- 하향 시는 위의 반대입니다.

## 4. 정리
- 지금 수치는 체감이 약하고 느리지만, 전라·함경·황해 시작을 조용히 밀어 주는 지역 편향이 있습니다.
- 경기 시작 보정이 필요하다면, 특산물 효과를 올리기보다 경기 지역 특산물 산지를 늘리거나 특산물 1종 효과를 '산지 수가 적은 나라일수록' 키우는 쪽이 독주 위험이 적습니다.
