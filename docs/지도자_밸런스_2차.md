# 지도자 밸런스 검토 (2차)

1차(`docs/지도자_밸런스.md`) 이후 바뀐 것: 기습 기본 85%, AI 평시 방어 건설·세율 유연화·연 1회 승리 목표, 건설비 50%, 전쟁 피로, 불행 지역 산출 감소.

## 방법

- 1차와 같음: 전원 AI 6세력, 시작 위치 무작위, 정치체제 전원 철인통치(반란 세력 포함), 360턴.
- 본 실험 180판(지도자 고유 호전성), 통제 실험 120판(전원 호전성 5 = 효과만 비교). 지도자당 41~52판 / 28~34판.
- 새로 기록한 것: 승리 유형, AI가 1년마다 고른 승리 목표, 행동(세율·선포·강화·전쟁 턴·편입·건설·생산·공격 방식·반란·전쟁 피로), 버프·디버프가 실제로 적용된 턴과 횟수(`tools/leader_tracking.py`). AI가 선택지를 평가하는 계산은 발동으로 치지 않습니다.
- **오차**: 종합 점유율(본·통제 평균)의 표준오차가 지도자당 ±2.1~3.5%p입니다. 1차→2차 사이에 8~10%p씩 움직인 지도자(광개토대왕·김구·김일성·세종)도 있어, 한 번의 결과만으로 수치를 크게 바꾸면 안 됩니다. 아래 제안은 두 차례에서 같은 방향인 신호와 발동 빈도(오차가 작음)를 우선했습니다.

1. **승리 유형이 두 가지뿐**입니다. 300판 중 정복·평화승리는 0회. 정복승리는 '마지막 한 세력'(반란 세력 포함)이어야 하는데 그보다 훨씬 먼저 경제승리(나머지 합의 2배를 10턴)가 납니다. 평화승리는 생존 세력 전원이 한 연합이어야 해서 사실상 불가능합니다. 랜드마크승리는 이번에 처음 나왔습니다(본 18판, 통제 17판).
2. **AI 목표는 62%가 경제**, 정복 19%, 랜드마크 11%, 평화 8%. 정복을 목표로 한 AI의 승리 25회는 모두 경제·랜드마크승리였습니다(정복 조건에 닿지 못함).
3. **호전 지도자(7~9)가 여전히 위**: 전쟁 턴 비율 58~71%, 판당 선포 5~6회·강화 6~8회로 짧은 전쟁을 반복하고, 평균 전쟁 피로가 20~25(상한 40)인데도 점령 이득이 더 큽니다. 온건 지도자(1~3)는 전쟁 턴 19~34%, 피로 5~9.
4. **세율**: AI 평균 6.6~8.4%. 호전 지도자가 더 낮습니다(전쟁 피로로 행복도가 낮아 세율을 내림 → 수입 감소라는 간접 페널티는 작동).
5. **반란이 드뭅니다**(판당 0~1.3건). 그래서 반란 관련 효과(견훤·선덕여왕 디버프, 이승만 디버프, 공민왕 디버프)는 거의 발동하지 않습니다.
6. **기습 비율 99~100%**: 기본 성공률 85%로는 AI 선택이 바뀌지 않아 돌격 관련 효과(광개토대왕 버프 3%, 무열왕 디버프 0회, 연개소문 버프 2%)가 여전히 거의 무효입니다.
7. **사용되지 않는 요소**: 해군·공군 유닛 생산 0 → 근초고왕 버프, 주몽·단군·김구·이성계 디버프 미발동. 거래는 사람만 하므로 무령왕 버프 미발동.

### 시스템 (지도자 밸런스 전체에 영향)

| | 문제 | 제안 |
|---|---|---|
| S1 | 정복·평화승리 0회 | 정복승리: **전체 지역 60% 이상 + 시작 세력 수도 과반 보유 10턴**. 평화승리: **한 연합이 생존 세력 2/3 이상·GDP 70% 이상을 24턴 유지** |
| S2 | 호전 AI가 전쟁 피로(평균 20~25)를 감수하고도 상위 | **선포한 쪽만 전쟁 피로 +5 추가**(방어 측은 그대로) 또는 피로 회복 0.5 → 0.4 |
| S3 | 반란이 판당 1건 안팎이라 반란 효과 무효 | 위 표대로 효과 교체(반란 빈도 자체는 유지) |
| S4 | 기습 99%, 돌격 효과 무효 | 기습 기본 85% → 80%, 또는 **방어선이 없는 지역 공격 시 돌격 공격 +10%**(돌격이 의미 있는 상황 만들기) |
| S5 | AI 해군·공군 0 | 섬·해안 세력 AI의 상륙함·구축함 생산, 폭격 대상이 있으면 폭격기 생산 |
