# AI 페이즈 설계 (초안)

지금 AI는 게임 처음부터 끝까지 하나의 공식으로 움직입니다. 이 설계는 나라마다 상황에 따라 **확장기(P1) → 경쟁기(P2) → 결승기(P3)**로 넘어가며, 페이즈마다 다른 목적과 공식으로 판단하게 합니다. 어느 페이즈에서든 **위기 모드**가 덧씌워질 수 있습니다.

- 근거 자료
  - v1.20.0 100판(`시뮬레이션_v1.20.0_100판.md`)
  - 페이즈 추적 60판: 3턴마다 인접 중립, 조우, 빈 슬롯, 재정 기록
  - v1.19.2 추적 100판(`분석_v1.19.2_11개항목.md`)
- 아직 구현하지 않은 설계입니다. 확인을 받으면 P1 → P2 → P3 순서로 나눠 구현하고, 단계마다 100판으로 확인합니다.

---

## 0. 원칙

1. **나라별 상태 기계**: 페이즈는 정해진 턴이 아니라 그 나라의 주변 상황으로 넘어갑니다.
   - 앞으로만 진행하고, 최소 체류 기간을 둡니다(왔다 갔다 하지 않게).
   - 위기 모드만 어느 페이즈에서든 들어갔다 나옵니다.
2. **정보 대등**: AI는 플레이어가 볼 수 있는 것만 씁니다. 시야, 조우, 외교 화면, 반기 랭킹, 지금까지 관측한 행동입니다.
   - 다른 나라의 숨은 호전성 수치는 쓰지 않고, *관측된 호전성*(최근 선전포고·비난·국경 집결)을 씁니다.
3. **성격은 계수**: 호전성·지도자 효과·정치체제는 '무엇을 하느냐'보다 '얼마나 세게 하느냐'를 바꿉니다. 같은 공식에 계수만 다릅니다.
4. **적절히 괴롭히기(가드레일)**:
   - 초반 기습 학살 금지
   - 한 대상에게 동시에 선전포고하는 나라 수 제한
   - 선전포고 전 예고 행동
   - 빠른 정복 독주 제동
   - 모두 플레이어와 AI에게 똑같이 적용합니다.
5. **돈을 놀리지 않기**: 페이즈마다 '이번 턴 쓸 수 있는 돈'을 현금 흐름으로 계산합니다.
   - 돈이 모자라 멈출 공사는 시작하지 않습니다.
   - 돈이 안 드는 확장 수단(편입으로 얻은 보병으로 무력 점령)을 함께 씁니다.

## 2. 공통 지표 (매 턴 나라 i마다 계산·캐시)

| 기호 | 뜻 |
|---|---|
| R | 내 지역 수 |
| Y | GDP |
| Î | 순수입 예상 = 지난 턴 세수 − 유지비 |
| M | 보유금 |
| M_res | 비상금 = 300 + 유지비 × 5 |
| N_adj | 내 영토와 맞닿은 중립 지역 수 |
| N_3 | 내 영토에서 3칸 안 중립 지역 수 |
| K | 조우한 나라 수 |
| B | 국경을 맞댄 나라 수 |
| P, P̂_j | 국력(기존 0.6 × 군사 + 0.4 × GDP), i가 추정한 j의 전력(안개 기준) |
| H_obs(j) | j의 관측된 호전성(0~10) = min(10, 2 × 최근 96턴 j의 선전포고 수 + 0.5 × 비난 수 + 국경 집결 지수) |
| V_j | j의 승리 진척(0~1) = max(과학 n/7, 경제 n/5, 정복 R_j/284, 외교 연합 비율). 반기 랭킹·외교 화면으로 아는 값만 |
| ETA_j | j가 이길 때까지 남은 턴 추정(5.1) |

## 3. 페이즈 전환

### P1 → P2 (확장기 끝)

아래 중 하나가 성립하고, P1에 12턴 이상 머물렀으면 넘어갑니다.

| 조건 | 뜻 | 자료상 시점 |
|---|---|---|
| N_adj ≤ max(2, 0.1R) | 손 닿는 빈 땅이 거의 없음 | 중앙 78턴 |
| B ≥ 2 이고 N_3 ≤ 0.25R | 두 나라와 붙었고 빈 땅도 줄어듦 | 60~80턴 |
| 더 강한 나라(P̂_j > 1.2P)에게 선전포고를 받음 | 확장을 멈추고 대응 | |
| 96턴 | 안전장치 | |

플레이어 체감(50~60턴)보다 조금 늦은 60~95턴에 넘어가는 나라가 많을 것으로 예상합니다.

### P2 → P3 (결승기 시작)

아래 둘 다 성립하면 넘어갑니다.

- **(a) 땅 쟁탈이 끝남**: 전체 중립 < 3% 이고, 내 N_adj = 0인 상태가 24턴 이상 지속.
- **(b) 누군가 승리에 가까워짐**: 어떤 나라(나 포함)든 V ≥ 0.4.
  - 과학 3/7, 경제 2/5, 정복 114곳, 외교 연합 40%.
  - 또는 240턴.

자료상 대략 200~260턴입니다.

### 위기 모드 (어느 페이즈든 덧씌움)

**들어가는 조건** (하나라도):
- 수도 인접에 적군이 있고 그 지역 전력비 < 1
- 한 전쟁에서 영토 25% 이상을 잃음
- 실질 평균 행복도 < −35
- 3턴 연속 자금 음수

**나오는 조건**: 6턴 동안 위 조건이 하나도 없음.

## 4. P1 확장기: '빈 땅을 가장 싸고 빠르게'

### 4.1 예산 (현금 흐름)

- 이번 턴 새 공사에 쓸 수 있는 턴당 금액:
  `A = Î − Σ(진행 중 공사의 턴당 비용) + (M − M_res) / 8`
- 비축은 8턴에 나눠 씁니다. P1은 비축을 쌓지 않습니다.
- 새 공사의 턴당 비용이 A보다 크면 시작하지 않습니다(멈출 공사는 시작하지 않음).

### 4.2 지역 슬롯 결정 순서

**1. 경계 지역(맞닿은 중립이 있음) → 편입**

점수는 `s = 가치 × 경합 / 편입 비용`입니다.

| 항목 | 정의 |
|---|---|
| 가치 | 산출 × 세율 × (36 − 소요 턴) + 식량 가치 + 자원 가산(석유·석탄 +30%, 해안·산맥 +10%: 과학 조건 미리 확보) |
| 경합 | 다른 나라 영토나 그 나라의 편입·점령 대상과 맞닿은 땅 1.5, 내 땅에 둘러싸인 안쪽 0.7 |

남과 다투는 땅을 먼저 잡고, 어차피 내 것이 될 안쪽은 나중에 잡습니다. A 안에서 점수 순으로 시작합니다.

**2. 안쪽 지역(맞닿은 중립 없음) → 생산 건물**

순서와 우선순위는 이렇습니다.
- 식량이 모자라면 농장·어장이 먼저입니다.
- 다음은 '추가 세수 ÷ 비용'이 높은 은행·공장입니다.
- 석탄·석유 지역이면 채굴, 연료가 남으면 발전소를 짓습니다.

**3. 편입 대상이 비싸서 A가 모자라면** 경계 지역도 생산 건물로 돌립니다(슬롯을 놀리지 않음).

### 4.3 무력 점령 (돈 안 드는 확장)

- 편입으로 얻은 보병과 시작 병력 가운데 보병 2개 이상인 부대가 대상입니다.
- 어떤 편입 대상과도 겹치지 않는 중립 지역을 점령하러 갑니다. 중립 수비대는 보병 1개입니다.
- 대상 점수는 `가치 × 경합 / (소요 턴 + 이동 턴)`입니다.
- 남기는 병력:
  - 수도 최소 방위군(기존 규칙)
  - 국경을 맞댄 나라 쪽 경계 지역마다 보병 1
- 점령이 끝난 부대는 다음 대상으로 바로 갑니다.

### 4.4 군사·외교

- **유닛 생산**: 잃은 만큼 보충하거나, 이웃 국경 집결로 위협도 ≥ 0.8인 경계에만 합니다.
- **조우 직후**: 관측된 호전성이 낮은 이웃(H_obs ≤ 4)과 우호 선언을 하고, 가능하면 불가침을 맺습니다. 내 호전성 ≥ 8이면 확률을 절반으로 줄입니다.
- **선전포고는 원칙적으로 하지 않습니다.** 예외('초반 기습')는 셋을 모두 만족할 때만입니다.
  - 내 호전성 ≥ 8
  - 상대 지역 ≤ 5곳이고 국지 전력비 ≥ 3
  - 내 인접 중립 ≤ 3
- 세율: 행복도가 버티는 한 기준 세율 +2%p까지 올립니다. 확장은 돈이 병목입니다.

**P1 기대 효과**
- 60턴 지역 중앙 37 → 45곳 이상
- 48턴 전쟁 중 비율 38% → 15% 이하
- 96턴 안 멸망 세력 10.6% → 5% 이하

## 5. P2 경쟁기: '방향을 정하고 이웃을 분류'

### 5.1 승리 방향 결정

24턴마다 다시 평가합니다. 바꾸려면 새 방향 점수가 지금 방향의 1.3배를 넘어야 합니다(바꾸는 비용).

**점수**: `U_k = Fit_k × Feas_k × Speed_k`

| 방향 | Fit(성격) | Feas(조건) | ETA(남은 턴 추정) |
|---|---|---|---|
| 정복 | 0.2 + 0.08 × 호전성 + 전쟁 성향 보정 | min(1.5, P / 이웃 평균 P̂) × (1 − 나를 겨누는 동맹 비율) | (284 − R) / 최근 48턴 지역 증가 속도 |
| 과학 | 0.2 + 0.06 × (10 − 호전성) + 과학 보정 | (해안·산맥·석유·공장 5 가능 지역) 충족 비율 × GDP 순위 계수 | 남은 과학 비용 / 순수입 |
| 경제 | 0.2 + 0.06 × (10 − 호전성) + 은행 보정 | 금융 권역 가능성(수도 + 맞닿은 내 지역 4곳) × min(1, 우호 선언 이상 관계 / 3) | 남은 경제 비용 / 순수입 |
| 외교 | 0.2 + 0.06 × (10 − 호전성) + 동맹 보정 (장보고는 0) | 우호도 30 이상인 나라 / (생존국 − 1) | 필요한 관계 단계 × 24턴 |

- `Speed_k = clamp(1.5 − ETA_k / 300, 0.2, 1.2)`
- 시간 종료는 별도 방향이 아닙니다. 네 점수가 모두 0.15 미만이면 '가장 크게 버티기'(확장·방어 위주)로 둡니다.

### 5.2 이웃 분류

국경을 맞댄 나라와 조우한 나라마다 12턴에 한 번 분류합니다.

| 값 | 공식 |
|---|---|
| 위협 T_j | (P̂_j / P) × (0.5 + H_obs(j)/10) × (j와 맞닿은 내 경계 비율 + 0.2) |
| 기회 O_j | (P / P̂_j) × 노획 가치_j / (1 + 방어선 평균 단계_j) |
| 친밀 F_j | 우호도/50 + 정치체제 유사(+0.2) + 공동의 적(+0.3) − 경쟁(+0.2 체제 대립) |
| 필요 N_j | 내 승리 방향에 j가 필요하면 1 (경제 파트너·외교 연합 후보) |

| 분류 | 조건(위에서부터) | 행동 |
|---|---|---|
| 위협 | T_j ≥ 1.2 | 그 경계 방어선·병력 우선. 불가침 시도. j의 다른 이웃과 우호·동맹(세력 균형) |
| 동반자 | F_j ≥ 0.5 이거나 (N_j = 1 이고 T_j < 1) | 우호 선언 → 조약 → 동맹 순서. 문턱까지 모자라면 선물(순수입의 10% 이내) |
| 표적 | 방향 = 정복, O_j ≥ 1.5, F_j < 0.2 | 표적은 한 번에 하나. 병력을 모으고 아래 조건이 되면 선포 |
| 중립 | 나머지 | 감시 |

**표적에 선포하는 조건**
- 전력비 ≥ 1.5 − 0.07 × 호전성
- 전쟁 피로 ≤ 30, 실질 행복 ≥ −10
- 3턴 전에 '예고'(국경 집결 또는 비난 또는 요구)

**전쟁 목표**: 표적 지역 4곳(호전성 8 이상이면 6곳). 목표 달성, 교착 12턴, 위기 모드 중 하나면 강화합니다.

### 5.3 압도적 강자에 대항하는 동맹 (P2부터)

- **대상**: 국력 비중 ≥ 30% 이고 2위의 1.5배인 나라 h(기존 패권 판정보다 조금 이르게).
- h와 동맹이 아닌 나라는 h를 '위협'으로 분류합니다.
- 서로의 조약·동맹 우호도 문턱을 −15 낮춥니다(기존 −20 할인을 대체·통합).
- h의 이웃끼리는 동맹 후보 점수에 +0.5를 줍니다.

### 5.4 방향별 내정

| 방향 | 내정 |
|---|---|
| 과학 | 공장 5·은행 5·석유 지역 확보. 다음 단계 비용을 비축 목표로 |
| 경제 | 수도 주변 금융 권역, 우호 선언 이상 관계 3곳 |
| 정복 | 사관학교·공장·전차. 표적 경계에 집결 |
| 외교 | 은행·선물 예산 |

## 6. P3 결승기: '달릴까, 막을까'

### 6.1 승리 예상 턴 (ETA) 추정

| 대상 | 추정 방법 |
|---|---|
| 다른 나라(반기 랭킹 기준) | 최근 두 번 랭킹 사이의 진척 변화로 속도를 구합니다. 과학은 단계 수 차이 ÷ 24턴, 경제는 단계 수 차이, 정복은 지역 수 차이. 그다음 ETA = 남은 진척 / 속도. 속도가 0이면 ∞ |
| 나 | 5.1의 ETA_k |

### 6.2 결정

아래 표에서 L은 '나를 뺀 나라 중 ETA가 가장 짧은 나라'입니다.

| 경우 | 조건 | 행동 |
|---|---|---|
| 질주 | ETA_me ≤ 0.8 × ETA_L | 내 방향에 올인. 새 전쟁 금지. 위협 이웃과 불가침, 가장 강한 이웃에게 선물. 경제·과학 단계 비용 비축 최우선 |
| 저지 | ETA_L ≤ 60턴 이고 L ≠ 나 | L이 맞닿았거나 동맹 경유로 닿으면 선전포고(연합 합산 전력비 ≥ 1.0). 목표는 L의 승리 거점 |
| 보통 | 그 밖 | P2 행동 유지(견제 강도만 P3 기준) |

**저지할 때 L의 승리 거점**

| L의 방향 | 노리는 곳 |
|---|---|
| 과학 | 발사대 지역, 추진체·모듈·연료 유닛, 수도 |
| 경제 | 수도(경제특구·기축통화), 국제금융센터 지역 |
| 정복 | 방어가 약한 L의 경계 지역을 빼앗아 284곳 아래로 |

- L과 닿지 않으면: L을 비난하고, L과 싸우는 나라에 선물(전쟁 자금)을 보내고, L을 견제하는 연합에 가입합니다.
- 저지 전쟁은 L의 ETA가 120턴 이상으로 물러나거나 위기 모드면 강화합니다.

### 6.3 정복 독주 제동 (v1.20.0의 빠른 정복 대응)

- 어떤 나라든(플레이어 포함) **200턴 전에 지도의 40%(171곳)**를 넘으면, 그 나라는 모든 나라에게 P3 기준 '저지 대상'이 됩니다(자기 페이즈와 무관).
- 승리 근접 견제(VICTORY_THREAT)에 정복 진척(R/284)을 더하되 **P3에서만** 씁니다. P2까지는 정복 견제가 없어 정복승리 자체는 살아 있습니다.
- 플레이어 알림: AI가 정복 기준의 75%(213곳)에 닿으면 경고합니다.
