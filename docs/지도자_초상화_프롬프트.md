# 지도자 초상화 만들기 (ChatGPT 이미지 생성용)

## 1. 공통 프롬프트

참고 자료(어진·표준영정·유물·사진)를 첨부하고, 아래 프롬프트의 `{지도자}`·`{시대·복식 메모}` 두 곳만 바꿔서 쓴다.
같은 대화창에서 이어 만들면 그림체가 더 잘 맞는다(첫 장이 마음에 들면 "앞 그림과 같은 그림체로"를 덧붙인다).

```
첨부한 자료(초상화·유물·사진)를 인물의 얼굴 생김새, 수염·머리 모양, 복식, 관모의 참고로 삼아
전략 게임의 지도자 초상화를 그려줘.

인물: {지도자}
시대·복식 메모: {시대·복식 메모}

[구도]
- 세로 3:4 비율, 가슴 위(머리부터 어깨·가슴 윗부분까지) 반신상
- 정면을 똑바로 바라보는 얼굴, 시선은 보는 사람을 향함, 좌우 대칭에 가까운 자세
- 머리 위에 관모가 있으면 잘리지 않게 위쪽 여백을 조금 둠, 얼굴이 화면 위쪽 1/3~1/2에 오게

[그림체]
- 깔끔한 반실사 디지털 페인팅(세미 리얼리즘), 부드러운 셀 셰이딩, 선은 얇고 깨끗하게
- 현대 전략 게임의 지도자 카드 느낌, 과장된 만화체·사진 같은 실사 모두 피함
- 조명은 왼쪽 위에서 오는 부드러운 빛 하나, 차분하고 품위 있는 표정
- 채도는 중간 정도, 색은 복식 본래 색을 살리되 전체적으로 따뜻하고 차분하게

[배경]
- 아주 연한 회청색(#F4F5F7) 단색에 가까운 배경, 가장자리로 갈수록 살짝 어두워지는 정도의 은은한 그라데이션만
- 무늬·소품·풍경·글자·테두리·서명·워터마크 없음

[출력]
- 600×800 픽셀 PNG
```
