# 지도자 디버프 개편안

> **반영됨**: 검토 후 수정된 최종안이 게임에 들어갔습니다. 최종 수치는 README의 '지도자 고유 디버프' 표와 `korciv/leaders.py`를 따릅니다. 아래 표는 처음 제안한 안입니다.

여러 지도자에게 똑같이 붙어 있던 단순 디버프를 정리하려는 안입니다. 대상은 AI 시작 우호도 감소(5명), 반란 확률(3명), 진압 성공률(2명), 세율 잠금(2명), 점령지 행복도(2명), 전쟁 피로(2명), 시작 자금(2명), 세율 초과 행복도(2명), 점령 턴(2명), 시장가(2명)입니다. 각 지도자의 역사적 배경에 맞춘 고유한 효과로 바꿉니다. 중복 묶음마다 배경에 가장 잘 맞는 한 명은 그대로 둡니다.

구현 난이도:
- **없음**: 기존 효과 키만 쓴다.
- **소**: 새 키 하나에 조건이 간단하다.
- **중**: 반란·외교·보급 같은 기존 규칙 안에 새로운 분기가 들어간다.

### 강도 변화 예상

| 기존보다 | 지도자 | 이유 |
|---|---|---|
| 약해짐 | 쿠빌라이 | AI가 상륙전을 드물게 쓴다 |
| 약해짐 | 광개토대왕 | 초반엔 디버프가 없고, 6년 이후에만 약해진다 |
| 강해짐 | 장보고 | 동맹을 못 맺는다 |
| 강해짐 | 홍타이지 | 영토가 커질수록 디버프가 커진다 |
| 조건부 | 연개소문, 이순신 | 수도 함락이나 해전 패배 때만 발동한다 |
| 비슷 | 나머지 | — |

반영하게 되면 한 번 더 시뮬레이션을 돌려 수치를 맞춥니다.

## 그대로 두는 지도자

| 묶음 | 남기는 지도자 | 이유 |
|---|---|---|
| 시작 자금 | 김대중 '외환위기 수습' | 그대로 들어맞는다 |
| 전쟁 피로 | 수 양제 '무리한 원정' | 원정 실패가 곧 왕조 멸망으로 이어졌다 |
| 세율 잠금 | 정조 '벽파 견제' | 당쟁에 묶인 국정 |
| 점령지 행복도 | 대조영 '유민 국가' | 고구려 유민과 말갈이 함께 산 이원 사회 |
| 세율 초과 | 박정희 '유신 체제' | — |
| 점령 턴 | 수로왕 '연맹 체제' | 가야는 끝내 연맹을 벗어나지 못했다 |
| 시장가 | 김일성 '자력갱생' | — |
| 군 생산비 | 안창호 '실력 양성 우선' | 교육·실력 양성을 무장 투쟁보다 앞세웠다 |

다른 지도자들은 이미 효과가 고유하므로 유지합니다: 단군왕검, 동명성왕, 태조 왕건, 태조 이성계, 이승만, 근초고왕, 진흥왕, 무령왕, 태종 무열왕, 광해군, 최영, 홍길동, 김구.

## 추가 제안 (선택): 숙적 관계

같은 판에 만나면 서로 시작 우호도 −30, 서로 싸울 때 공격력 +5%:
- 연개소문 ↔ 당 태종
- 수 양제 ↔ 동명성왕·광개토대왕·연개소문
- 이순신 ↔ 도요토미 히데요시
- 공민왕 ↔ 쿠빌라이 칸
- 광해군 ↔ 홍타이지
- 김구·안창호 ↔ 이토 히로부미
- 최영 ↔ 태조 이성계
- 궁예·견훤 ↔ 태조 왕건
- 이승만 ↔ 김일성

지도자 특성과 상관없는 맛내기 규칙입니다. 지금까지의 일반적인 우호도 디버프를 특정 상대로 좁혀 둔 형태입니다.
