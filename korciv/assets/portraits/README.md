# 지도자 초상화

이 폴더에 `<지도자 키>.png` 파일을 넣으면 시작 화면과 외교 탭에 자동으로 표시됩니다. 파일이 없는 지도자는 빈 틀(실루엣)이 나옵니다.

## 규격

- 비율: **세로 3:4** (가로:세로 = 3:4)
- 권장 크기: **600 × 800 px** (최소 300 × 400). 화면에는 120 × 160 논리 픽셀로 나오며, 고해상도 화면을 위해 넉넉히 둡니다.
- 형식: PNG 권장 (`.jpg`/`.jpeg`/`.webp`도 읽음, 같은 키에 여러 개가 있으면 png → jpg → jpeg → webp 순)
- 비율이 다르면 가운데를 기준으로 잘라 3:4로 맞춥니다. 얼굴이 위쪽 1/3~1/2에 오도록 구도를 잡아 주세요.
- 파일명: 소문자 영문 키 그대로 (예: `sejong.png`). 직접 입력 지도자는 `custom.png`.
