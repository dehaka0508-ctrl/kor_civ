# 지도자 초상화

이 폴더에 `<3글자 코드>.png` 파일을 넣으면 시작 화면과 외교 탭에 자동으로 표시됩니다. 파일이 없는 지도자는 빈 틀(실루엣)이 나옵니다.

## 규격

- 비율: **세로 3:4** (가로:세로 = 3:4)
- 권장 크기: **600 × 800 px** 이상 (최소 300 × 400)
- 형식: PNG 권장 (`.jpg`/`.jpeg`/`.webp`도 읽음)
- 비율이 다르면 가운데를 기준으로 잘라 3:4로 맞춥니다. 얼굴이 위쪽 1/3~1/2에 오도록 구도를 잡아 주세요.
- 파일명: 아래 3글자 코드, 소문자 (예: `sej.png`).

ChatGPT용 초상화 프롬프트는 `docs/지도자_초상화_프롬프트.md`에 있습니다.
