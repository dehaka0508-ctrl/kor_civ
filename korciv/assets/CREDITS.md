# 그림 출처

`tools/build_flag_assets.py`로 만든 파일입니다.

| 파일 | 출처 | 라이선스 |
|---|---|---|
| `emblems/tiger.png` | game-icons.net — Delapouite, "Tiger head" | CC BY 3.0 |
| `emblems/dragon.png` | 용 실루엣 — 123RF 무료 이미지(제작자 제공) | 123RF 무료 이미지 약관 |
| `emblems/om.png` | Noto Sans Devanagari(Google)의 ॐ 글자 | SIL OFL 1.1 |
| `emblems/pine.png` | 직접 그림(스크립트) | — |
| `emblems/cloud.png` | 구름무늬 — 크라우드픽 무료 이미지(제작자 제공) | 크라우드픽 이용 약관 |
| `emblems/cheonma.png` | 천마도 실루엣 — urbanbrush.net 이미지(제작자 제공) | urbanbrush 이용 약관 |
| `emblems/samjogo.png` | 삼족오 문양 — 제작자 제공 이미지 | 제작자 확인 |
| `flags/taegeukgi.png`, `flags/eogi.png`, `flags/goryeo.png` | 제작자 제공 이미지 | 제작자 확인 |
| 인공기 | 코드로 그림(`ui/art.py`) | — |

game-icons.net 아이콘(호랑이 머리)은 Creative Commons Attribution 3.0 (https://creativecommons.org/licenses/by/3.0/) 에 따라 사용합니다.
