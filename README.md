# 한반도 시군구 문명

한반도 시군구 424곳(남한 227, 북한 194, 남북 병합 3)을 한 칸씩 타일로 쓰는 1주 단위 턴제 전략게임입니다.
`docs/기획서.md`(종합 기획서)와 `korciv/data/regions.csv`, `adjacency-overrides.csv`를 바탕으로 Python + pygame으로 만들었습니다.

![지도](docs/screenshot.png)

## 실행

```bash
pip install -r requirements.txt      # pygame, numpy
python -m korciv                      # 게임 시작 (1440×900, 최소 1280×800)
python -m korciv --simulate 200       # 창 없이 AI끼리 200턴 진행 후 결과 출력
python -m pytest                      # 테스트 (pytest 필요)
```

## 조작

| 입력 | 동작 |
| --- | --- |
| 좌클릭 | 구역·해역 선택 (좌측 정보 패널) |
| 우클릭 | 선택한 부대의 이동·공격·상륙·폭격 대상 지정 (마우스를 올리면 예상 교전 결과 표시) |
| 휠 / `+` `-` / 더블클릭 | 확대·축소 (0.8~8배, 2배부터 구역 이름, 4배부터 인구 배지) |
| 드래그 / 방향키 | 지도 이동 |
| `Enter` | 턴 종료 |
| `Tab` / `A` | 빈 슬롯 순회 / 빈 슬롯 AI 추천으로 자동 지정 |
| `1`~`7` | 지도 모드: 정치·행복도·인구·자원·군사·우호도·조선 8도 |
| `F1` `F2` `F5` `F9` | 도움말 · 개발자 안개 토글 · 저장 · 불러오기 |
| `Ctrl+D` | 다크 모드 |

화면 구성은 기획서 13절을 따릅니다: 상단 국가 상태 바(수치 hover 시 내역), 가운데 지도, 좌측 구역 정보,
우측 행동·부대·국가 탭, 좌하단 지도 모드, 우하단 턴 종료 버튼(미지정 슬롯 배지).

## 구현한 규칙

기획서 3~11절의 수치는 모두 `korciv/config.py`(밸런스 상수)와 `korciv/leaders.py`(지도자 24명·정치체제 7종)에 있습니다.

- **턴·슬롯** — 1턴=1주, 지역마다 슬롯 1개(건설·유닛 생산·편입), 비용은 매 턴 분납, 자금 부족 시 정지, 취소 시 50% 환급. 턴 종료 처리 순서(외교→이동→해전→폭격→지상 공격→점령·편입→건설·생산→자원→세수→인구→행복도→반란)도 기획서 순서 그대로입니다.
- **경제** — Y = 30P + 150g(F) + 150g(S) + 1000g(M)φ + 600g(B) + 9000K, 연료 배수 φ, 발전소·석탄액화, 정유·탄광·자체발전, 식량(자동 구매 옵션)·기근, 시장(같은 턴 추가 구매 +10%), 특산물 자동 배분, 랜드마크, 천도.
- **인구·행복도·반란** — 성장 공식과 상한, 기근·이주, 세율·전쟁·생산·해산·피폭·랜드마크·특산물 요인, 0.99 수렴, 반란 확률 p(H)와 수용·진압·독립.
- **군사** — 유닛 9종, 자국 영토 2칸·그 밖 1칸 이동, 연륙교, 해군 턴당 2단계(항구↔해역↔상륙), 공군 반경 3칸, 돌격·기습·폭격·대공·공중전·해전·나포·건물 파괴, 방어선(경계별)·방공호·대공포·사관학교·공항·항구, 점령 T(P)와 즉시 병합, 중립 편입.
- **외교** — 우호도 증감표, 우호→통행권·불가침→동맹→연합 4단계, 거래 판정(m = 1.1 − 우호도/250, 수정 제안), 요구·선물, 선전포고(동맹 자동 참전, 연합 공동 참전)·강화(24턴 불가침), 패권 견제, 국력.
- **승리** — 정복·경제·평화·랜드마크 (설정에서 켜고 끔), 연말 랭킹.
- **AI** — 대전략(12턴)·작전(슬롯 유틸리티)·전술(교전 기대 손익)·외교(선전포고 점수 W, 강화, 조약) 4층, 플레이어와 같은 안개 규칙, 난이도 6단계(인구 성장률·생산 수입 배수).
- **전장의 안개** — 없음 / 지도 공개 / 미탐색. 시야 밖은 마지막 정보를 채도를 낮춰 표시합니다.

## 기획서와 다르거나 보완한 부분

- **근사 경계**: 원자료에 경계가 없는 평양 중심 17개 구역+승호구역, 라선 2개 구역은 대표 좌표 기반 보로노이 분할로 근사했습니다.
- **도하 ×0.9**는 하천 데이터가 없어 연륙교 경유 공격에 적용합니다. 어장 조건 '바다·하천 인접'은 해안 구역(또는 이미 어장이 있는 구역)으로 봅니다.
- **해로 편입**: 항구가 있는 지역은 같은 해역의 중립 해안 지역도 편입할 수 있습니다(무연륙 섬 시작 세력이 확장할 수 있도록).
- **보완 규칙**(config에서 조정): 자금이 음수인 턴에는 전 지역 행복도 −1, 세력 수 상한 24(넘으면 독립 지역은 중립이 됨), 반란으로 인한 독립 전쟁에는 선전포고 행복도 벌칙을 적용하지 않음(연쇄 반란 방지). 진압 실패 시 독립 지역은 기획서대로 '내 영토 중 무작위'이며 `REBEL_INDEPENDENCE = "rebel_region"`으로 반란 지역 자체로 바꿀 수 있습니다.
- **편의 기능**: 영토가 커지면 슬롯이 많아지므로 빈 슬롯 AI 추천 자동 지정(버튼·`A`키·매 턴 자동 옵션)을 넣었습니다.
- **단순화**: 특산물 배분은 자동(행복도 낮은 지역 우선), 공군 재배치는 공항 간만(항공모함 탑재는 항구에서 부대 합치기), 요격 전투기는 목표와 인접 지역에서 집계, 해전의 폭격기는 항모 탑재분만 계산, 공항 20대 상한과 연합 내 자동 자원 거래는 미구현입니다. 인구는 내부적으로 실수로 저장하고 0.1 단위로 표시합니다.
- **밸런스 메모**: 기획서 수치 그대로면 편입 비용(100 + 20P)이 세수에 비해 싸서 AI가 40턴 안팎에 중립 지역을 대부분 편입합니다. `ANNEX_BASE_COST`, `ANNEX_COST_PER_POP`, `G_MAX` 등으로 조정하세요.
